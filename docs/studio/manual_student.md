# คู่มือนักเรียน — APCC Studio

เส้นทางของเรามี 3 ขั้น: **🎯 ฝึก → 🛠️ สร้าง → 🌏 แบ่งปัน**
ดูว่าตัวเองอยู่ขั้นไหนได้ที่กล่อง **APCC Studio** บนหน้า **แดชบอร์ด**

---

## ขั้นที่ 1 🎯 ฝึก — ผ่านด่านทักษะ

มี 4 ด่าน: **ลำดับ/รับ-แสดงผล → การตัดสินใจ → การทำซ้ำ → ลิสต์และฟังก์ชัน**
แต่ละด่านต้องทำโจทย์ฝึกให้ **ผ่านทุก test case** ได้ประมาณ 6 ใน 10 ข้อ แดชบอร์ดจะบอกว่าเหลืออีกกี่ข้อ

### ทำโจทย์
1. กดชื่อรายวิชา → เลือกโจทย์ทางซ้าย
2. เขียนโค้ด → กด **▶ ทดสอบตัวอย่าง** ได้ไม่จำกัดครั้ง → พร้อมแล้วกด **Submit**

### 🧩 โจทย์เรียงบรรทัด (Parsons)
- คลิกหรือลากบล็อกจากซ้ายไปวางในช่อง **โปรแกรมของฉัน**
- ใช้ ◀ ▶ ปรับการย่อหน้า (สำคัญมากในไพทอน) ใช้ ▲ ▼ เลื่อนลำดับ ใช้ ✕ เอาออก
- กด **✔ ตรวจลำดับ** เพื่อดูว่าบรรทัดไหนยังผิด (ไม่นับคะแนน) แล้วกด **Submit** เพื่อส่งจริง
- บางข้อมี **บล็อกหลอก** ที่ไม่ต้องใช้

### 💡 ขอคำใบ้
หลัง Submit แล้วยังไม่ผ่าน กด **ขอคำใบ้ระดับที่ 1** ได้
- ระดับ 1–4 เป็น **คำใบ้จากครู** จากคำถามชวนคิด ไปจนเกือบเป็นคำตอบ ลองระดับต่ำก่อน
- ใช้ครบแล้วยังติด: แก้โค้ด → Submit อีกครั้ง → กด **🔄 วิเคราะห์โค้ดที่ส่งล่าสุด** ให้ AI ช่วยดู
- ข้อสอบ (🏆) ไม่มีคำใบ้

### 🗣️ อธิบายโค้ดของฉัน (Explain-Back)
ผ่านโจทย์ระดับปานกลางหรือยากแล้ว จะมีกล่องให้พิสูจน์ว่าเข้าใจโค้ดของตัวเอง **ไม่มีผลกับคะแนน** เลือกทำอย่างใดอย่างหนึ่ง
- **✍️ อธิบาย**: เขียน 2–3 ประโยค ว่าโค้ด *รับอะไร → ทำอะไร → แสดงอะไร* โดยอ้างชื่อตัวแปรในโค้ด
- **🔮 ทำนายผล**: ระบบให้ข้อมูลชุดใหม่ ให้เดาว่าโค้ดของเราจะแสดงอะไร

แล้วตอบคำถามคิดต่ออีก 1 ข้อ ถ้ายังไม่พร้อม กด "ไว้ทีหลัง" ได้

### 📚 Learning Hub
กดลิงก์ **📚 Learning Hub** ในกล่อง APCC Studio บนแดชบอร์ด (หรือปุ่ม **🧪 Learning Tools** ในหน้ารายวิชาของฉัน) มี 12 หัวข้อภาษาไพทอน พร้อมโค้ดตัวอย่างอธิบายทีละบรรทัด ติดตรงไหนดูที่นี่ก่อน

## ขั้นที่ 2 🛠️ สร้าง — ทำนวัตกรรมกับทีม

ผ่านครบ 4 ด่าน จะมีปุ่ม **🛠️ เปิด Project Studio** บนแดชบอร์ด

1. **ตั้งทีม**: ไปที่ **TeamSync** → คนหนึ่งสร้างทีม แล้วบอก **รหัสทีม 6 ตัว** ให้เพื่อนพิมพ์เข้าร่วม
2. **สร้างโปรเจกต์** ตั้งชื่อ (เปลี่ยนภายหลังได้)
3. ทำบอร์ด **5 ขั้น** ทีละขั้น กด 💾 บันทึกทุกครั้ง ขั้นที่ครบจะมี ✓
   1. 👥 **เข้าใจผู้ใช้**: คุยหรือสังเกตผู้ใช้จริงอย่างน้อย 2 คน — *ห้ามใส่ข้อมูลส่วนตัวของเขา เช่น เบอร์โทร หรือชื่อเต็ม*
   2. 🎯 **นิยามปัญหา**: "[ผู้ใช้] ต้องการ [อะไร] เพราะ [อะไร]" และจะวัดความสำเร็จอย่างไร
   3. 💡 **ออกแบบ**: คิดอย่างน้อย 3 ไอเดีย เลือก 1 ไอเดียพร้อมเหตุผล และออกแบบว่าโปรแกรม รับ → ประมวลผล → แสดง อะไร
   4. 🛠️ **สร้างต้นแบบ**
      - **Kit A**: เขียนเว็บแอป Streamlit ในหน้าเว็บ → **▶ รันเว็บแอป** (ครั้งแรกรอ 10–30 วินาที) → **💾 บันทึกรุ่น** ทุกครั้งที่ปรับ
      - **Kit B**: ใส่ลิงก์ Google Colab ของทีม
   5. 🧪 **ทดสอบกับผู้ใช้** 2 รอบ: บันทึกผลรอบแรก สิ่งที่ปรับ และผลรอบสอง
4. **🧭 Design Coach**: กดเมื่อคิดไม่ออก โค้ชจะ *ถามคำถาม* ให้คิดต่อ ไม่ทำงานแทน
5. **👀 ประเมินทีมอื่น**: ลองผลงานเพื่อน ให้ระดับ 1–4 ตามรูบริก และเขียน "สิ่งที่ชอบ + ข้อเสนอแนะ 1 ข้อ"
6. **📝 ผลประเมิน**: ดูคะแนนจากครู (เมื่อครูกดเผยแพร่) และคำแนะนำจากเพื่อน

**รูบริก 20 คะแนน**
- 4 เกณฑ์ของทีม: เข้าใจปัญหาและผู้ใช้, แนวทางแก้ปัญหา, การทำงานของโปรแกรม, การทดสอบและปรับปรุง
- 1 เกณฑ์รายบุคคล: **ความเข้าใจโค้ด** ทุกคนต้องอธิบายโค้ดที่ตัวเองทำได้

## ขั้นที่ 3 🌏 แบ่งปัน

ผลงานที่ครูคัดเลือกจะขึ้น **แกลเลอรี** ให้ทุกคนในรายวิชาลองใช้ เปิดได้จากลิงก์ 🌏 แกลเลอรี บนแดชบอร์ด
ลิงก์ **📁 พอร์ตโฟลิโอ** รวมผลงานทั้งหมดของเรา กด 🖨️ เพื่อพิมพ์หรือบันทึกเป็น PDF ใส่แฟ้มสะสมผลงาน

## กติกาการใช้ AI

- AI ใน APCC (คำใบ้ Design Coach Explain-Back) มีไว้ **ช่วยคิด** ไม่ได้ทำงานแทน
- ใช้ AI ภายนอกช่วยเรียนได้ แต่ **ต้องอธิบายโค้ดที่ส่งได้เอง** เพราะครูดูจาก Explain-Back และเกณฑ์ความเข้าใจโค้ดรายบุคคล

## ปัญหาที่พบบ่อย

| ปัญหา | ทำอย่างไร |
|---|---|
| ไม่เห็นปุ่ม Project Studio | ดูแดชบอร์ดว่าเหลือด่านไหน แล้วไปฝึกต่อ |
| กด Submit แล้วรอนาน | ระบบตรวจกำลังทำงาน รอสักครู่ อย่ากดซ้ำรัวๆ |
| เว็บแอปไม่ขึ้น | รอให้โหลดครบ แล้วกด ▶ รันเว็บแอป อีกครั้ง ถ้าขึ้นกรอบแดง แปลว่าโค้ดผิด อ่านบรรทัดที่บอก |
| เข้าทีมไม่ได้ | ตรวจรหัสทีม 6 ตัวให้ถูก (ตัวพิมพ์ใหญ่) |
| Parsons กด Submit แล้วได้ 0 | ตรวจการย่อหน้า ◀ ▶ และอย่าใช้บล็อกหลอก |
