  - การตั้งค่า Studio บันทึกแยกจากปุ่มบันทึกรายวิชาเดิม
- **Course Template Pack** (`js/studio/templatePack.js`, หน้า `#/teacher/studio/templates`)
  - นำเข้าชุดโจทย์ JSON พร้อมดูตัวอย่าง (dry-run) และตรวจข้อมูลผิดก่อนบันทึก

  - ปุ่ม "ตรวจเฉลยก่อนนำเข้า" รันเฉลยกับทุก test case ผ่าน runner เดิม (`runSingleTest`) โดยไม่แก้ `grader.js`

  - คลัง template (`studio_templates`) เก็บชุดโจทย์รวมเฉลย อ่านได้เฉพาะครู
  - ส่งออกรายวิชาเป็นไฟล์ JSON โดยไม่มีข้อมูลนักเรียน
- **Lazy loader** (`js/studio/studioLoader.js`): ไฟล์ Studio โหลดเฉพาะตอนเข้าหน้า Studio รายวิชาเดิมโหลดเพิ่มเพียง 2 ไฟล์เล็ก
- **firestore.rules**: เพิ่มบล็อก `studio_templates` และ `studio_events` ต่อท้ายไฟล์ ไม่แก้กฎเดิม
