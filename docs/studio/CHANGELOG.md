## v6.0-phase1 — 13 พ.ย. 2569 — Studio Core + Course Template Pack

**สิ่งที่เพิ่ม**
- **Studio Core** (`js/studio/studioConfig.js`)
  - `isStudio(course)` และ `hasFeature(course, key)` เป็นด่านเดียวที่ทุกฟีเจอร์ Studio ต้องผ่าน
  - รายวิชาวิจัย 8 วิชา (ว31281 ทุกรุ่น และ Sandbox1–3) เปิด Studio ไม่ได้ แม้มีฟิลด์ `studio` อยู่ก็ตาม
- **ส่วน "เปิดใช้ APCC Studio"** ในหน้าแก้ไขรายวิชา
  - เลือก template ได้ 4 แบบ: w23207, w23103_ch2, generic_python, web_basic
  - เปิด/ปิดได้ทีละฟีเจอร์ (9 ฟีเจอร์ ค่าเริ่มต้นเป็นปิด)
  - การตั้งค่า Studio บันทึกแยกจากปุ่มบันทึกรายวิชาเดิม
- **Course Template Pack** (`js/studio/templatePack.js`, หน้า `#/teacher/studio/templates`)
  - นำเข้าชุดโจทย์ JSON พร้อมดูตัวอย่าง (dry-run) และตรวจข้อมูลผิดก่อนบันทึก
  - ตรวจโจทย์ซ้ำจาก `sourceProblemId` หรือรหัสหน้าชื่อโจทย์ จึงไม่สร้างโจทย์ซ้ำ
  - ปุ่ม "ตรวจเฉลยก่อนนำเข้า" รันเฉลยกับทุก test case ผ่าน runner เดิม (`runSingleTest`) โดยไม่แก้ `grader.js`
  - เติมข้อมูล Studio ให้โจทย์เดิม (D1): เพิ่มเฉพาะฟิลด์ optional ที่ยังไม่มี และบันทึกค่าก่อนแก้ลง `studio_events` ทุกข้อ
  - คลัง template (`studio_templates`) เก็บชุดโจทย์รวมเฉลย อ่านได้เฉพาะครู
  - ส่งออกรายวิชาเป็นไฟล์ JSON โดยไม่มีข้อมูลนักเรียน
- **Lazy loader** (`js/studio/studioLoader.js`): ไฟล์ Studio โหลดเฉพาะตอนเข้าหน้า Studio รายวิชาเดิมโหลดเพิ่มเพียง 2 ไฟล์เล็ก
- **firestore.rules**: เพิ่มบล็อก `studio_templates` และ `studio_events` ต่อท้ายไฟล์ ไม่แก้กฎเดิม
