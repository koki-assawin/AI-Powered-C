## เงื่อนไขของชุดข้อมูล

**1. ช่วงคะแนน 75–82%** — คะแนน E1 รวมของแต่ละคนเป็น 45, 46, 47, 48 หรือ 49 จาก 60 (75.0 / 76.7 / 78.3 / 80.0 / 81.7%) โดยแจกเป้าหมายตามลำดับ 48, 47, 49, 46, 45 ทุกวิชาจึงมีคนที่ได้ 80% พอดี ซึ่งเป็นเส้นเกรด A ในระบบ

ไม่สามารถทำให้ทุกข้อได้ 75–82% ได้ เพราะคะแนนรายข้อมาจากสัดส่วนกรณีทดสอบที่ผ่าน ข้อที่มี 1–3 กรณีทดสอบได้คะแนนแค่ 0 / 33 / 50 / 67 / 100% ข้อที่มี 4, 5 หรือ 10 กรณีทดสอบจึงได้ 75–82% โดยตรง (491 ครั้งที่ส่ง) ส่วนข้ออื่นได้ 100% หรือคะแนนบางส่วน ตัวอย่างใน `SUBMISSIONS.csv` เช่นกิจกรรม 3-A3 มีกรณีทดสอบ 1+1+1+10+10 คะแนน จึงได้ 43 → 87 → 91%

**2. การส่งซ้ำ** — ประมาณ 35% ของข้อต่อคน (อย่างน้อย 2 ข้อ) เลือกจากข้อที่ทำคะแนน 40–60% ได้จริง

- ครั้งแรกได้ 40–60% บางข้อมีครั้งกลางที่ดีขึ้น แล้วครั้งสุดท้ายได้คะแนนจริงของข้อนั้น
- ช่วงห่างระหว่างการส่ง 8–180 นาที หรือกลับมาแก้ข้ามวัน (12–48 ชั่วโมง) ประมาณ 1 ใน 4
- คะแนนไม่ลดลงระหว่างการส่ง คะแนนล่าสุดจึงเท่ากับคะแนนสูงสุดเสมอ ทั้งเกณฑ์ latest และ best ให้ E1 ตรงกันทุกคน
- ทุก submission มี `attemptNo` / `attemptsTotal` และ `scenario: "borderline-75-82-iterative"`

**3. ขอบเขตการแก้ไข**

- แก้ได้เฉพาะ 3 วิชาที่ระบุไว้ในสคริปต์ (`SANDBOX_COURSES`) ไม่รับ courseId จาก command line
- ก่อนเขียน ตรวจว่ารายวิชามี `isSandbox: true` จำนวนนักเรียนตรง 30 / 9 / 3 นักเรียนทุกคนเป็นผู้ใช้ Sandbox และไม่มีเอกสารที่ไม่ใช่ Sandbox ปนอยู่ ถ้าวิชาใดไม่ผ่าน จะหยุดทั้งหมด
- ลบและสร้างใหม่เฉพาะ `submissions` และ `grades` ในเอกสาร `courses` เพิ่มแค่ `scenario`, `scenarioSeed`, `scenarioUpdatedAt`
- ไม่แตะ assignments, testCases, users, enrollments และรายวิชาที่มีข้อมูลจริง

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | เนื้อหา |
|---|---|
| `SUBMISSIONS.csv` | การส่งงานทุกครั้ง (1,101 แถว) วิชา นักเรียน หน่วย โจทย์ ครั้งที่ส่ง เวลา (เวลาไทย) สถานะ กรณีทดสอบที่ผ่าน คะแนน % และ `isFinal = Y` ถ้าเป็นครั้งที่สมุดเกรดใช้ |
| `GRADEBOOK.csv` | คะแนนที่ใช้ต่อคนต่อข้อ (A01–A20, %) และ E1 รวม /60 |
| `STUDENT_SUMMARY.csv` | สรุปรายคน E1 รวม ร้อยละ ตำแหน่งเทียบ 80% (`below` / `equal` / `above`) E1 ตามเกณฑ์ latest, best และสมุดเกรด จำนวนข้อที่ส่งซ้ำ และจำนวนครั้งที่ส่งทั้งหมด |

E1 คำนวณด้วยสูตรเดียวกับตาราง E1 ในหน้า Teacher Analytics คือผลรวมของ `round(คะแนน% × rawScore / 100)` ของโจทย์ที่เผยแพร่และระบุหน่วย

## คำสั่ง

```
node scripts/seed-sandbox-course-update.js            # ทดลอง แสดงแผน ไม่เขียน
node scripts/seed-sandbox-course-update.js --apply    # สร้างข้อมูลชุดนี้ใหม่ (seed เดิม ได้คะแนนชุดเดิม)
node scripts/seed-sandbox-course-update.js --verify   # ตรวจข้อมูลปัจจุบัน อ่านอย่างเดียว
node scripts/export-sandbox-e1.js                     # ส่งออก CSV ในโฟลเดอร์นี้ใหม่
```

การรัน `--apply` ซ้ำจะได้คะแนนชุดเดิม แต่เวลาส่งจะนับย้อนจากวันที่รัน และ ID ของ submission จะเปลี่ยน
