## สูตรที่หน้าจอใช้คำนวณกราฟเรดาร์ 5 มิติ

อ้างอิง `js/pages/teacher/StudentAnalytics.js` ส่วน `_StudentRadarChart` ทุกมิติปรับเป็นสเกล 0-100 และใช้ "คะแนนตัวแทนต่อกิจกรรม" หนึ่งค่าเท่านั้น ในโหมดคะแนนล่าสุดคือคะแนนของการส่งครั้งหลังสุดของกิจกรรมนั้น

| มิติ | สูตร | หมายเหตุ |
|---|---|---|
| คะแนนเฉลี่ย | ค่าเฉลี่ยของคะแนนตัวแทนทุกกิจกรรมที่เคยส่ง | หน่วยเป็นร้อยละอยู่แล้ว |
| อัตราผ่าน | สัดส่วนกิจกรรมที่คะแนนตัวแทน ≥ 60 | เกณฑ์ 60 ไม่ใช่ 100 |
| ครอบคลุม | (จำนวนกิจกรรมที่เคยส่ง ÷ จำนวนกิจกรรมทั้งหมดในรายวิชา) × 100 | ตัวหารคือ **29** ซึ่งรวมกิจกรรมที่ยังไม่เผยแพร่ด้วย ไม่ใช่ 20 กิจกรรมที่นับคะแนน |
| ความพยายาม | min(100, (จำนวนการส่งทั้งหมด ÷ จำนวนกิจกรรมที่เคยส่ง) ÷ 5 × 100) | ส่งเฉลี่ย 5 ครั้งต่อข้อ = 100 |
| พัฒนาการ | min(100, max(0, 50 + ค่าเฉลี่ยของ (คะแนนสูงสุด − คะแนนครั้งแรก) ต่อกิจกรรม)) | ไม่พัฒนาเลย = 50 |

**ข้อควรระวังสองข้อ**

1. มิติ "พัฒนาการ" ใช้ (สูงสุด − ครั้งแรก) เสมอ **ไม่เปลี่ยนตามโหมดที่เลือก** ค่าจึงเท่ากันทั้งโหมดคะแนนสูงสุดและคะแนนล่าสุด
2. แท็บ "กลุ่มผู้เรียน" จัดกลุ่ม A-D จากสูตรเดียวกันแต่ **ใช้โหมดคะแนนสูงสุดเสมอ** ไม่ได้ใช้โหมดคะแนนล่าสุด รายงานนี้จึงแสดงทั้งสองค่าเพื่อไม่ให้สับสน

**เกณฑ์จัดกลุ่ม** (`classifyProfile` ไล่ตามลำดับ A → B → C → D ข้อแรกที่เข้าเกณฑ์ชนะ)

```text
A: คะแนนเฉลี่ย >= 65 และ อัตราผ่าน >= 60 และ ครอบคลุม >= 60
B: คะแนนเฉลี่ย >= 60 และ อัตราผ่าน >= 55 และ ครอบคลุม < 60
C: ครอบคลุม >= 50 และ ความพยายาม >= 50
D: นอกเหนือจากนั้น
```
