## สคริปต์ที่ทำซ้ำได้

ทุกไฟล์สร้างจากสคริปต์ใน `tools/report/` ซึ่งอ่านจากแคชใน `backups/report-cache/` (ไม่ขึ้น GitHub เพราะมีชื่อจริง)

```
node tools/report/fetch-cache.js        # ดึงข้อมูลหลักครั้งเดียว
node tools/report/fetch-testcases.js    # กรณีทดสอบของกิจกรรมที่นับคะแนน
node tools/report/fetch-all-courses.js  # ข้อมูลของทุกรายวิชา (ใช้กับ P6)
node tools/report/audit-1c.js           # P1
node tools/report/sample-work-l34.js    # P2
node tools/report/case-profiles.js      # P3
node tools/report/version-history.js    # P4
node tools/report/system-facts.js       # P5
node tools/report/field-trial.js        # P6
node tools/report/open-issues.js        # P7
```

`_mapping_private.csv` เก็บไว้ในเครื่องเท่านั้น อยู่ใน `.gitignore` ห้ามแนบไปกับเอกสารที่เผยแพร่
