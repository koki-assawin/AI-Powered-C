### 2.1 โค้ดครั้งที่ 1 (ไม่ผ่าน)

```c
#include <stdio.h>

int main() {
int i,sum = 0;
for(i=1, i<=10, i++) {
sum +=i;
}
printf("sum = %d", &sum);
return 0;
}
```
