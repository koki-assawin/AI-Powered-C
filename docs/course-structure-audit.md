## 3. สรุปตัวเลขรวม

### 3.1 คะแนนเต็มรวมที่นับเข้า E1
**ไม่ทราบ** — ค่านี้คำนวณสดจากฐานข้อมูล ไม่ได้เก็บเป็นค่าคงที่ไว้ที่ใด

สูตรที่ระบบใช้ (`js/pages/teacher/StudentAnalytics.js:1003`):

```
totalRaw = ผลรวม rawScore ของทุกกิจกรรมที่ isPublished !== false และมี unitName
```

ระบบแสดงผลลัพธ์นี้ให้ครูเห็นอยู่แล้วที่หัวตาราง E1 ว่า "คะแนนเต็มรวม X คะแนน · Y คน · Z โจทย์" (`js/pages/teacher/StudentAnalytics.js:1045`)

เท่าที่ยืนยันได้จากโค้ด: **เฉพาะชุดกิจกรรมหน่วยที่ 5 รวมกันได้ 100 คะแนนดิบ** (50+15+15+20) ถ้าเผยแพร่ครบทั้ง 4 ข้อ คะแนนเต็มของหน่วยที่ 5 หน่วยเดียวก็เกิน 60 คะแนนที่ระบุในเอกสารแล้ว

### 3.2 คะแนนเต็มแยกรายหน่วย
ระบบคำนวณรายหน่วยด้วยสูตรเดียวกัน คือผลรวม `rawScore` ของกิจกรรมในหน่วยนั้น (`js/pages/teacher/StudentAnalytics.js:1085`) แล้วแสดงเป็นคอลัมน์ "รวม (หน่วย)" ในตาราง E1

| หน่วย | คะแนนเต็มตามที่ตรวจได้ |
|---|---|
| หน่วยที่ 1 | ไม่ทราบ (อยู่ในฐานข้อมูล) |
| หน่วยที่ 2 | ไม่ทราบ |
| หน่วยที่ 3 | ไม่ทราบ — ยกเว้นกิจกรรม 3.1 ที่ตั้งไว้ 100 คะแนน |
| หน่วยที่ 4 | ไม่ทราบ |
| หน่วยที่ 5 | 100 (เฉพาะชุดที่ระบบสร้างให้ และต้องกดเผยแพร่ก่อน) |

### 3.3 กิจกรรมที่ตั้งค่าไว้แต่ไม่เคยมีใครส่ง
**ตรวจไม่ได้จากโค้ด** ต้องเทียบ `assignments.id` กับ `submissions.assignmentId` ในฐานข้อมูลจริง

สิ่งที่บอกได้คือ **ตาราง E1 ไม่ได้แยกกรณีนี้ออก** กิจกรรมที่ไม่มีใครส่งเลยยังถูกนับอยู่ในตัวหารของคะแนนเต็ม (`js/pages/teacher/StudentAnalytics.js:1003` นับทุกชิ้นที่เผยแพร่และมีหน่วย โดยไม่ดูว่ามี submission หรือไม่) ทำให้คะแนนเต็มรวมอาจสูงกว่าที่ใช้สอนจริง

## 4. สูตรคะแนนที่ระบบใช้

### 4.1 คะแนนต่อการส่ง 1 ครั้ง (โจทย์เขียนโค้ด)
`js/grader.js:244-247`

```
pointsEarned = ผลรวม points ของกรณีทดสอบที่ผ่าน   (ค่าเริ่มต้น 1 ถ้าไม่ได้ตั้ง)
totalPoints  = ผลรวม points ของกรณีทดสอบทั้งหมด
score        = ปัดเศษ(pointsEarned / totalPoints x 100)   ได้ผลเป็นร้อยละเสมอ
```

- ตรวจทั้งกรณีทดสอบแบบเปิดและแบบซ่อน (`js/grader.js:225-228` ดึงทุกเคสโดยไม่กรอง `isHidden`)
- เทียบผลลัพธ์แบบตรงตัวอักษร หลังแปลง CRLF เป็น LF และตัดช่องว่างหัวท้าย (`js/grader.js:110-113`)
- ค่าเริ่มต้นของคะแนนต่อเคสในหน้าจัดการคือ 10 (`js/pages/teacher/TestCaseEditor.js:10`)

### 4.2 ส่งหลายครั้ง — ระบบใช้ครั้งที่ดีที่สุด
`js/grader.js:326-349` ฟังก์ชัน `updateBestGrade` เขียนลง `grades` และอัปเดตเฉพาะเมื่อคะแนนใหม่สูงกว่าเดิม (`js/grader.js:344`)
ตาราง E1 ก็ใช้ค่าที่ดีที่สุดเช่นกัน โดยรวมจาก `submissions` + `grades` + `submissions_v2` แล้วเลือกค่าสูงสุด (`js/pages/teacher/StudentAnalytics.js:980-999`)

### 4.3 แปลงร้อยละเป็นคะแนนดิบ
`js/pages/teacher/StudentAnalytics.js:1023` และฝั่งนักเรียน `js/pages/student/Gradebook.js:284`

```
คะแนนดิบที่ได้ = ปัดเศษ(ร้อยละที่ดีที่สุด x rawScore / 100)
```

`rawScore` เป็นค่าที่ครูกรอกเองต่อกิจกรรม จำกัดไม่เกิน 100 (`js/pages/teacher/AssignmentManager.js:881`)

### 4.4 คะแนนกิจกรรมรูปแบบใหม่ (assignments_v2)
- Loop Autopsy: `js/pages/student/StudentActivityView.js:97-99` — **ให้คะแนนเต็มของกรณีนั้นทันทีเมื่อคำตอบยาวเกิน 20 ตัวอักษร** ไม่ได้ตรวจความถูกต้องของเนื้อหา
- Quiz Blitz: `js/pages/student/StudentActivityView.js:351-353` — รวมคะแนนจากข้อที่ตอบถูก
- ทั้งสองแบบเก็บ `score` เป็นร้อยละ พร้อม `rawScore` และ `maxScore` และถือว่าผ่านที่ 60%

## 6. ข้อสังเกตที่ควรจัดการก่อนยื่น

1. **80 ชั่วโมง กับ 74 ชั่วโมง** — เอกสารโครงสร้างรายวิชาระบุ 80 ชั่วโมง 2.0 หน่วยกิต แต่เอกสารวิทยฐานะระบุ 74 ชั่วโมง
2. **คะแนนเต็มรวมไม่ได้ถูกตรึงไว้ที่ 60** — ถ้าต้องการให้ E1 รวมได้ 60 พอดี ต้องปรับ `rawScore` รายข้อในระบบเอง ระบบไม่ได้ปรับสัดส่วนให้อัตโนมัติ
3. **กิจกรรม 3.1 อาจไม่ถูกนับเข้า E1** — สคริปต์ `seed-activity-31.js:84-130` ไม่ได้ตั้งค่า `unitName` ให้กิจกรรม ขณะที่ตาราง E1 ตัดรายการที่ไม่มี `unitName` ทิ้ง (`StudentAnalytics.js:966`) ควรเปิดหน้าจัดการกิจกรรมตรวจว่าตั้งหน่วยไว้แล้วหรือยัง
4. **กิจกรรมหน่วยที่ 5 ถูกสร้างเป็นสถานะซ่อน** (`AssignmentManager.js:439`) ถ้ายังไม่กดเผยแพร่ นักเรียนจะไม่เห็น และคะแนนจะไม่เข้า E1
5. **การตรวจ Loop Autopsy ให้คะแนนจากความยาวคำตอบ** (เกิน 20 ตัวอักษร) ไม่ได้ตรวจความถูกต้อง ถ้ารายงานอ้างว่าเป็น "การตรวจอัตโนมัติ" ควรระบุให้ตรงว่าเป็นคะแนนการมีส่วนร่วม ไม่ใช่การตรวจถูกผิด
6. **ข้อสอบ (assignmentType = exam) ถูกนับรวมใน E1 ด้วย** ถ้ามี `unitName` และเผยแพร่อยู่ เพราะตัวกรองที่บรรทัด 966 ไม่ได้แยกประเภท ควรตรวจว่าคะแนนสอบไม่ถูกนับซ้ำกับคะแนนระหว่างเรียน
7. **กิจกรรมที่ไม่มีใครส่งยังถูกนับในตัวหาร** ดูหัวข้อ 3.3
8. **โค้ดจัดหมวดหน่วยไม่ตรงกับเอกสารโครงสร้างรายวิชา 2 จุด** — `js/pages/student/games/EthicsQuiz.js:2` เขียนว่าจริยธรรม AI อยู่ "หน่วยที่ 4 แผนที่ 34" และ `js/pages/student/TeamSync.js:2` เขียนว่า Mini Project อยู่ "หน่วยที่ 4 แผนที่ 35-37" ขณะที่เอกสารโครงสร้างรายวิชาจัดทั้งสองเรื่องไว้ในหน่วยที่ 5
